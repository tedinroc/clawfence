01 · The problem

Approvals are exhausting.
So people turn them off.

And then one poisoned file is enough.
0
questions asked in the baseline
5
unsafe actions executed: secrets, egress, delete, messages, out-of-scope writes
The cope
Auto mode exists because per-call approval is a full-time job.
The missing layer is not another approval button. It is knowing what the task actually authorises.
02 · Insight

Intent is the contract nobody writes down.

So ClawFence derives it, then enforces it.
1
Intent card
Named paths, domains, recipients, effect classes, spend cap. Unclear authority stays out.
2
Action tuple
Exec, patch, files, URLs, messages, MCP tools. Effects and reversibility are explicit.
3
Adjudication
Rules first: outside scope blocks; ambiguous escalates. The decision model is optional, never the hard block.
The adjudicator sees only the tuple and the card — never tool output, page text, or model reasoning.
Injected content has no channel into the decision.
03 · The human moment

Two taps. Not another chat tab.

The arbiter shows the task, the tool, the target, and the reason.
Physical
Phone today. Cardputer next.

Approve resumes the paused call; deny blocks it and leaves the target untouched.

STOP aborts the whole run.
