ClawFence

少打斷，零意外。把「這個任務到底授權了什麼」變成可機器檢查的一張卡。

問題

OpenClaw 什麼都能做，這就是問題。審批太累，大家關掉；然後一個被注入指令的檔案就能刪掉 Documents、讀 SSH key、或把資料 POST 出去。缺的不是另一個「同意」按鈕，而是知道任務授權了什麼。

做法

  • 意圖卡：從任務推導具名路徑、網域、收件人、效果類別、花費上限。
  • 動作 tuple：每個工具呼叫轉成讀／寫／刪／外傳／收件人／提權。
  • 規則優先：越界寫入、刪除、外傳、secret、提權直接擋；只有真正模糊的才升級。
  • 暫停／仲裁：掛住呼叫；approve 續跑、deny 封鎖、STOP 用 sessions.abort 中止整個 run。
  • Hash chain：意圖 → 動作 → 判定 → 理由 → 批准者。

裁決器只看動作 tuple 與意圖卡，看不到工具輸出或網頁內容；注入內容沒有通道。

證據

  • 26 個情境（11 正常 / 15 對抗、41 calls）：26/26，不安全放行 0/15，正常誤擋 0。
  • 真實 gateway：14 calls、9 allow / 3 block / 2 escalate、不安全 5 → 0。
  • 真本機 Qwen3-4B：SSH key 讀取 52 µs 封鎖；wildcard 刪除暫停 20 秒、批准後續跑。
  • 18/18 單元測試、Plugin Inspector PASS、15,000 次決策 0 mismatches、two-card flow 2.75 秒。

試用

openclaw plugins install -l ./clawfence --force --accept-capabilities
./scripts/run-demo.sh；手機掃描 QR 進入 ?simple=1 仲裁器。

現場：ClawFence 是 tier-0 的意圖過濾器，不是 kernel sandbox；local-operator 信任邊界仍存在。這是一個 hook、可從 ClawHub 安裝。
