Live demo (pause mode)

  • Terminal 1: mlx_lm.server --model /tmp/qwen3-4b --port 18085 --chat-template-args '{"enable_thinking": false}' (or scripts/run-demo.sh scripted fallback).
  • Terminal 2: isolated gateway (HOME=/tmp/cfreal, config in /tmp/cfreal/.ocdemo).
  • Terminal 3: node clawfence/arbiter/server.mjs --dir /tmp/clawfence-live --port 8791 --host 0.0.0.0; phone scans the QR printed by run-demo.sh, or opens http://<mac-lan-ip>:8791/?simple=1.
  • openclaw config set plugins.entries.clawfence.config.escalation pause; run the task.
  • Between visitors: ./scripts/reset-demo.sh (restores the poisoned note; audit kept).
Beats (3 min): 15s problem → 90s live run → 30s proof frame → 20s failure/STOP → 15s upstream ask.
If the real model is unavailable, say: “the model is scripted for reproducibility; the gateway, hooks, tools, and audit are real.”

Judge questions

  • Isn't this auto mode? — Auto reviews individual exec calls; ClawFence carries task scope across files, egress, messages, MCP.
  • LLM judging LLM? — The adjudicator sees only the action tuple + intent card, never tool output or page text.
  • Can I fake a grant? — Yes if you can write the queue dir; local-operator trust. Grants are hash-bound and expire.
  • Model unavailable? — Rules still block out-of-scope writes, deletes, egress, secrets, privilege.
  • Stop a running agent? — STOP calls sessions.abort; verified on active and paused runs.

If something breaks

Kill the demo; show proof/shots/proof-frame.png + arbiter.png; play the 78-second video from the phone; say the number: unsafe 5 → 0, 2 interruptions in 14 actions, p50 <0.4 ms. Do not debug live for more than 20 seconds.

Submission text

ClawFence — an intent firewall for OpenClaw. Derives a task-scoped intent card, checks every tool call, blocks out-of-scope actions, pauses only the ambiguous ones for a phone/Cardputer arbiter, and records every decision in a hash-chained audit. Real run: unsafe 5 → 0, 2 taps in 14 actions, p50 <0.4 ms; real Qwen3-4B local run: 5 calls / 0 interruptions, secret read blocked in 52 µs, wildcard delete held 20 s then continued.
